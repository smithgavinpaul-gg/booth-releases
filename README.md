# Booth

Installers for **Booth**, a CDJ-style DJ player for macOS and Windows. Download from
**[the latest release](https://github.com/smithgavinpaul-gg/booth-releases/releases/latest)**.

- **macOS** (Apple Silicon): open `Booth_*_aarch64.dmg` and drag Booth into Applications. The first time only,
  right-click Booth → Open (or System Settings → Privacy & Security → **Open Anyway**): it isn't notarised.
- **Windows:** run `Booth_*_x64-setup.exe`. No admin rights needed. If Windows says it protected your PC:
  **More info → Run anyway** (it isn't code-signed).

After that Booth checks for a new version each time it starts, downloads it in the background and shows
**UPDATE ▸** in the top bar. Click it with the decks paused to restart into the new version. Updates are signed;
Booth refuses one that isn't.

This repository only holds the releases.
